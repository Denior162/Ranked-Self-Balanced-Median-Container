# Ranked-Self-Balanced-Median-Container
Ranked Median Container: Formal Verification of Self-Balancing Two-Heap Structures in Idris.

## Prerequisites
Ensure you have Nix installed with Flakes enabled.
### Run via Nix
You can build and execute the Idris program in a single command without globally installing Idris:
```
nix develop --command idris2 -x main src/idris2/Main.idr
```
